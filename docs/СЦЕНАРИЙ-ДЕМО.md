# Сценарий демо для жюри и видео (до 5 минут)

## Прогулка для жюри (2 минуты, с телефона)

1. Открыть ссылку → лендинг. Обратить внимание: **«концепт, не официальный сервис»**.
2. «Открыть демо» → карточки двух студентов. Войти как **Анна**.
3. Главная: следующая пара, средний балл, дедлайн, активная заявка.
4. Расписание → «Неделя»: показать бейджи «перенос», «замена», «отменено».
5. Учёба: средний балл, закрытые з.е., «статус сессии».
6. Заявки → «Новая заявка» → «Справка об обучении» → 2 поля → проверка → отправить.
   Открыть заявку: таймлайн. Подождать ~20 секунд — статус меняется сам, приходит
   уведомление.
7. Открыть помощника → «Когда окна?» → «Мои долги» → «Заказать справку» (создаёт заявку).
8. **Проверка безопасности:** войти как Анна и открыть `#/requests/req_2001` (заявка
   Марка) → экран 403.
9. Войти как **Марк**: другие данные, долг по дискретной математике.
10. Войти как **сотрудник деканата**: все заявки, поиск, смена статуса — у студента
    появляется уведомление.

## Видео на 3–4 минуты (раскадровка)

| Время | Кадр | Текст за кадром |
|---|---|---|
| 0:00–0:20 | Лендинг, скролл по блокам | «Деканат+ — концепт кабинета, где всё в одном месте. Это не официальный сервис» |
| 0:20–0:40 | Демо-аккаунты | «Два студента с разными данными и кабинет сотрудника» |
| 0:40–1:20 | Главная, мобильный экран | «Первый экран отвечает на вопрос — что у меня сейчас» |
| 1:20–1:50 | Расписание, неделя | «Переносы и замены видны сразу, а не в чате» |
| 1:50–2:20 | Учёба | «Понятная картина: средний балл, долги, статус сессии» |
| 2:20–3:10 | Создание заявки + таймлайн | «Заявка как доставка: видно каждый этап и срок» |
| 3:10–3:40 | Помощник | «Можно просто написать: когда окна?» |
| 3:40–4:10 | 403 + изоляция данных | «Чужие данные недоступны даже по прямой ссылке» |
| 4:10–4:30 | Сотрудник деканата | «Сотрудник меняет статус — студент получает уведомление» |
| 4:30–4:50 | Тёмная тема, десктоп, PWA | «Работает на телефоне, ставится на главный экран» |

## Что говорить про ИИ (для критерия «нейротехнологии»)

- Код писали ИИ-ассистенты по постановке задачи; вручную — выбор концепции, проверка
  текстов, тестирование, деплой.
- Помощник в продукте — **rule-based**, без внешних API: это осознанное решение, чтобы
  демо работало без ключей, стоило 0 ₽ и не зависело от доступности LLM.
